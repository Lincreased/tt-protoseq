- Last full check: 2026-10-04. FACT-006 and FACT-020 keep their 2026-10-02 check. Last update: 2026-10-07 (step 2 results).
- Main-table statuses: confirmed (read in the cited source on the "Checked" date); measured (observed in this project's own runs: in CI, source = run URL + commit; locally, source = LOCAL with the commit of the files, the script and the tool version). For measured rows "Checked" is the date the run output was read. to-check, inference and [unknown] appear only under "Unconfirmed".
- LOCAL rows depend on the owner's machine: their logs are not in the repository, so they are reproduced by rerunning the script, not by reading a run page.
- IDs are permanent and never reused. An unconfirmed item keeps its ID when it is confirmed or measured and moves to the main table; an unconfirmed item that other facts make moot is removed and recorded under "Changed since".
- Step: step from pio_steps.md; Z = the ZedBoard part of steps 3–4; context = background not used by steps 1–4; after 4 = queue after step 4.
- Vivado/Vitis 2025.2 commands, flags and GUI paths: verify in your version.
- Zynq mini is out of scope for part 1: no facts are recorded for it; treat anything about it as [unknown].
- Branch-based sources move: recheck before freezing conventions and before submission.
